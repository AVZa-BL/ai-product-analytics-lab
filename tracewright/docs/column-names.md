# Column names and cell words the importer recognises

Generated from the code by `python -m tracewright.sheets.docs`. Do not edit this file by hand: a
test fails if it differs from the generated text. To change what is recognised, change
`src/tracewright/sheets/layout.py` or `values.py` and regenerate.

A header is compared with case, spaces and punctuation ignored, so `Event Name`, `event_name` and
`EVENT NAME*` are all the spelling `eventname`. A header that is not in the table can be named with
`--map NAME=HEADER`. Two columns that both fit one meaning are an error until you choose with
`--map`. A column that fits no meaning is refused unless you add `--ignore-other-columns`.

## Meanings and the header spellings recognised for each

| Meaning | What it is | Recognised headers (as compared) |
| --- | --- | --- |
| `event` | The event name. Required. | `event`, `eventname`, `eventnames`, `trackingevent`, `trackingcall`, `trackcall`, `call`, `calls`, `eventtitle` |
| `property` | The property name. Empty on a row that describes the event only. | `property`, `propertyname`, `parameter`, `parametername`, `param`, `paramname`, `attribute`, `attributename`, `field`, `fieldname`, `eventproperty`, `eventparameter`, `propertykey`, `key` |
| `type` | The property's data type (see the words below). Empty means `string`. | `type`, `datatype`, `propertytype`, `parametertype`, `paramtype`, `valuetype`, `fieldtype`, `attributetype`, `dtype` |
| `required` | Whether the property is always sent (yes/no, true/false, 1/0, a tick). | `required`, `mandatory`, `isrequired`, `requiredfield` |
| `pii` | Whether the property is personal data (same spellings). | `pii`, `personaldata`, `containspii`, `ispii`, `sensitive` |
| `allowed_values` | For an `enum`: the permitted values (a bar, semicolon, comma or newline between). | `allowedvalues`, `values`, `possiblevalues`, `enumvalues`, `validvalues`, `valuelist`, `options` |
| `description` | Of the property on a property row; of the event on a row with no property. | `description`, `propertydescription`, `parameterdescription`, `desc`, `propertydesc`, `attributedescription`, `fielddescription` |
| `event_description` | Of the event, on any row. If present, `description` is only the property's. | `eventdescription`, `eventdesc`, `descriptionofevent`, `eventdefinition` |
| `trigger` | When the event is sent. Describes the event; the same on every row of it. | `trigger`, `eventtrigger`, `triggercondition`, `firewhen`, `fireswhen`, `whenfired`, `whentofire`, `triggeredwhen`, `when` |
| `owner` | Who owns the event. Describes the event. | `owner`, `eventowner`, `ownedby`, `responsible`, `team`, `dri` |
| `status` | `active`, `planned` or `deprecated` (see the words below). Describes the event. | `status`, `eventstatus`, `implementationstatus`, `state` |

## Type words

Parentheses and what follows them are ignored (`string (max 50)`).

| Plan type | Words |
| --- | --- |
| `string` | `string`, `str`, `text`, `varchar`, `char`, `uuid`, `guid`, `id`, `url`, `uri` |
| `integer` | `integer`, `int`, `long`, `bigint`, `smallint`, `int32`, `int64`, `uint`, `count` |
| `number` | `number`, `float`, `double`, `decimal`, `numeric`, `real`, `float32`, `float64` |
| `boolean` | `boolean`, `bool`, `flag` |
| `timestamp` | `timestamp`, `datetime`, `date`, `time`, `iso8601`, `datetimeoffset`, `utc` |
| `enum` | `enum`, `enumeration`, `select`, `choice`, `category`, `oneof` |

Refused with a reason, because a plan has no lists or objects: `any`, `array`, `dict`, `dictionary`, `json`, `list`, `map`, `object`, `set`, `struct`. Add a word of your own with `--type-map 'Word=string'`.

## Yes and no

For `required` and `pii`. Yes: `true`, `t`, `yes`, `y`, `1`, `x`, `required`, `mandatory`, a tick (✓ ✔ ☑). No: `false`, `f`, `no`, `n`, `0`, `optional`, `-`, a cross (✗ ✘ ☐). An empty cell is left unset.
