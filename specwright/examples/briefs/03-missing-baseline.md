# Harbor Tales: new tutorial

We rebuilt the Harbor Tales tutorial and want an A/B test of the new one against the old one.

**Hypothesis.** More new players finish the new tutorial than the old one.

**Who.** New players, assigned per player at the first launch of the game, 50/50 between the old
tutorial (control) and the new one (variant_a). Exposure is the moment the tutorial screen is
shown, which happens before any difference between the arms. 2,500 new players start the
game every day. We plan 14 days and would not stop before 7.

**Metric.** Tutorial completion rate. We have never measured it, so there is no baseline yet.
We would like the new tutorial to improve it by 8% relative. Alpha 0.05, power 80%, two-sided.

**Procedure.** Read once at the end of the test. Check the sample ratio daily. Owner: onboarding.
